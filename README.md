# ESP32-S3 Admin Toolkit

**Клавиатура, мышь и диагностика Windows с телефона через Bluetooth.** Для платы **LILYGO T-Dongle-S3 V1.1**. Плата подключается к компьютеру по USB, телефон — к плате по BLE (без Wi-Fi).

## Как начать

1. **Установи прошивку.** На компьютере открой установщик по ссылке выше. Подключи T-Dongle-S3 по USB в режиме BOOT (удерживай BOOT при подключении), выбери порт `USB JTAG/serial debug unit` и нажми «Установить Admin Toolkit». После прошивки переподключи плату как обычно.
2. **Открой панель на телефоне.** В Android Chrome перейди по ссылке «Открыть веб-панель управления», нажми **«Подключить ESP32»** и выбери устройство `AdminToolkit-S3`.
3. **Управляй ПК.** На вкладке «Клавиатура» вставь текст и нажми **«Отправить текст»**. Кнопка **«Очистить поле»** удаляет введённое из поля телефона без отправки на компьютер. Есть также клавиши, мышь и тачпад.
4. **Проверь компьютер.** Подключи плату к разблокированному Windows-ПК, установи раскладку **ENG**, затем в панели выбери «Диагностика» → «Железо и IP» → **«Старт проверки»**. PowerShell выполняется в видимом окне.

## Железо и IP: реестр компьютеров

Это основной режим для обхода рабочих ПК. По кнопке «Старт проверки» определяется **имя компьютера, модель платы, процессор, все модули ОЗУ (тип/размер/частота), физические диски (HDD/SSD/NVMe и ёмкость), активные IPv4 и MAC физических сетевых карт**. Мыши, клавиатуры, мониторы, принтеры и журналы Windows в этот отчёт не входят.

После новой успешной диагностики запись **автоматически сохраняется в браузере телефона**. При повторной проверке того же ПК сведения обновляются. Старый отчёт из ESP32 можно добавить вручную, предварительно проверив имя ПК и дату. В разделе «Реестр компьютеров» нажми **«Скачать Excel (.xlsx)»**: файл содержит листы «Сводка», «Компьютеры», «ОЗУ», «Диски», «Сеть».

**Реестр хранится только в браузере этого телефона** (localStorage): он не синхронизируется с GitHub и исчезнет при очистке данных сайта/браузера. Регулярно сохраняй Excel-файл. Отключённые физические адаптеры отображаются без IP, а несуществующие адреса не придумываются. Если Windows не смогла точно определить тип памяти или диска, будет указан «Unknown».

## Дополнительные режимы диагностики

- **Быстрая инвентаризация:** модель ПК, CPU, RAM, накопители, Windows, IP/MAC и основные сведения о системе.
- **Расширенная диагностика:** дополнительно программы, устройства, учётные записи, службы, события и настройки защиты. Некоторые сведения могут быть недоступны без соответствующих прав.

**«Последний отчёт ESP32»** показывает ранее сохранённый результат: он может быть от другого компьютера, если новая проверка не удалась. Сверяй имя ПК и дату сбора данных.

**Запуск при Restricted (v0.5.2).** Если Windows запрещает локальные .ps1 стандартной политикой `Restricted`, Admin Toolkit временно выбирает `RemoteSigned` **только для текущего процесса PowerShell** и в блоке `finally` возвращает точно прежнее значение `Process`. Настройки `CurrentUser` и `LocalMachine` не меняются, перезагрузка не нужна. Файл временного сборщика удаляется после работы. Если действует ограничение через GPO (`MachinePolicy` / `UserPolicy`), программа не меняет политику и сообщает об ошибке. Запускать диагностику следует на компьютерах, где это согласовано с IT-службой.

**Закрытие консоли (v0.5.2).** После успешной передачи отчёта, восстановления временной политики PowerShell и закрытия USB COM-порта окно PowerShell закрывается автоматически. Если сборщик завершился ошибкой до этой точки, окно остаётся открытым, чтобы можно было прочитать сообщение об ошибке. Режим Windows XP пока не реализован: его ручное окно cmd.exe этот механизм не закрывает.

## Исходный код и подробности

- `web/` — веб-панель и установщик.
- `firmware/` — прошивка ESP32-S3 (PlatformIO).
- `collectors/windows/` — диагностический PowerShell-сборщик.
- `tests/` — автоматические проверки.
- [История разработки, технические детали и старые версии](docs/DEVELOPMENT_HISTORY.md).

Для локальной сборки прошивки: `pio run -d firmware`. Веб-панель доступна по ссылке выше и не требует локального сервера.
