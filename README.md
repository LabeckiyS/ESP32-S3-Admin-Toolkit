# ESP32-S3 Admin Toolkit

**Клавиатура, мышь и диагностика Windows с телефона через Bluetooth.** Для платы **LILYGO T-Dongle-S3 V1.1**. Плата подключается к компьютеру по USB, телефон — к плате по BLE (без Wi-Fi).

## Как начать

1. **Установи прошивку.** На компьютере открой установщик по ссылке выше. Подключи T-Dongle-S3 по USB в режиме BOOT (удерживай BOOT при подключении), выбери порт `USB JTAG/serial debug unit` и нажми «Установить Admin Toolkit». После прошивки переподключи плату как обычно.
2. **Открой панель на телефоне.** В Android Chrome перейди по ссылке «Открыть веб-панель управления», нажми **«Подключить ESP32»** и выбери устройство `AdminToolkit-S3`.
3. **Управляй ПК.** На вкладке «Клавиатура» вставь текст и нажми **«Отправить текст»**. Кнопка **«Очистить поле»** удаляет введённое из поля телефона без отправки на компьютер. Есть также клавиши, мышь и тачпад.
4. **Проверь компьютер.** Подключи плату к разблокированному Windows-ПК, установи раскладку **ENG**, затем в панели выбери «Диагностика» → «Базовая диагностика» или «Расширенная диагностика» → **«Старт проверки»**. PowerShell выполняется в видимом окне.

## Два режима диагностики

- **Базовая диагностика:** имя и модель ПК, материнская плата, процессор, планки ОЗУ с типом DDR/объёмом/частотой, физические диски с типом HDD/SSD/NVMe и объёмом, активные IP и MAC, разделы, видеокарта и основные параметры Windows.
- **Расширенная диагностика:** всё из базовой, а также подробности Windows, учётные записи, установленное ПО, устройства, журналы и состояние защиты.

В **обоих режимах** используется один и тот же сборщик физических дисков и модулей памяти. Если Windows не знает их тип, программа покажет «не определён», а не предположительную характеристику.

## Реестр компьютеров и выгрузка Excel

После новой успешной диагностики любого из двух режимов сведения о железе и IP автоматически добавляются в реестр телефона. Повторная проверка того же компьютера обновляет запись. После обхода рабочих мест нажми **«Скачать Excel (.xlsx)»**: пять листов «Сводка», «Компьютеры», «ОЗУ», «Диски», «Сеть». Для сохранённого в ESP32 старого отчёта предусмотрено ручное добавление после сверки имени ПК.

Реестр хранится **только в браузере телефона** (localStorage), без синхронизации с GitHub. Экспортируй Excel после обхода — очистка данных браузера удалит накопленные записи.

**«Последний отчёт ESP32»** показывает ранее сохранённый результат: он может быть от другого компьютера, если новая проверка не удалась. Сверяй имя ПК и дату сбора данных.

**Запуск при Restricted (v0.6.0).** Если Windows запрещает локальные .ps1 стандартной политикой `Restricted`, Admin Toolkit временно выбирает `RemoteSigned` **только для текущего процесса PowerShell** и в блоке `finally` возвращает точно прежнее значение `Process`. Настройки `CurrentUser` и `LocalMachine` не меняются, перезагрузка не нужна. Файл временного сборщика удаляется после работы. Если действует ограничение через GPO (`MachinePolicy` / `UserPolicy`), программа не меняет политику и сообщает об ошибке. Запускать диагностику следует на компьютерах, где это согласовано с IT-службой.

**Закрытие консоли (v0.6.0).** После успешной передачи отчёта, восстановления временной политики PowerShell и закрытия USB COM-порта окно PowerShell закрывается автоматически. Если сборщик завершился ошибкой до этой точки, окно остаётся открытым, чтобы можно было прочитать сообщение об ошибке. Windows XP не поддерживается.

## Исходный код и подробности

- `web/` — веб-панель и установщик.
- `firmware/` — прошивка ESP32-S3 (PlatformIO).
- `collectors/windows/` — диагностический PowerShell-сборщик.
- `tests/` — автоматические проверки.
- [История разработки, технические детали и старые версии](docs/DEVELOPMENT_HISTORY.md).

Для локальной сборки прошивки: `pio run -d firmware`. Веб-панель доступна по ссылке выше и не требует локального сервера.
