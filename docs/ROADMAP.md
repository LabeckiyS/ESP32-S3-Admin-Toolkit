# План верификации и развития

## Milestone 1 · 0.1

- [x] Исходники отдельного проекта подготовлены локально.
- [x] PowerShell 5.1 collector, TXT/JSON и экспорт по USB CDC.
- [x] Приём в LittleFS с CRC32; BLE GATT RX/TX; интерфейс Chrome.
- [x] Юнит-тесты CRC/протокольных допущений, статический контроль исходников.
- [ ] Скомпилировать конкретный firmware target с доступным PlatformIO toolchain.

- [ ] Проверить загрузку и USB-передачу на тестовом ПК.
- [ ] Проверить BLE Notify на Android Chrome (S25 Ultra).
- [ ] Проверить работу после прерывания питания на каждом этапе.

- [x] Автоматический запрос отчёта по BLE после `P|DONE`.
