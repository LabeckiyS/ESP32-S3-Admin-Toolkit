# Состав read-only технической диагностики ESP32-S3 Admin Toolkit (v0.3.8)

Цель — инвентаризация **с согласия владельца/администратора ПК**. Windows не меняется; установки служб, изменения пользователей, политик, сетевых настроек и очистка журналов не выполняются. Данные собираются в памяти и передаются по USB CDC в ESP32. Отчётные файлы на Windows/телефоне не создаются; временный PowerShell-скрипт во время запуска сохраняется в TEMP. На ESP32 JSON хранится в LittleFS, браузер преобразует его в копируемый текст.

## Поля, реально реализованные в сборщике

| Категория | Поля |
|---|---|
| Компьютер | Имя, время сбора, изготовитель/модель, домен (факт присоединения), Windows/версия/сборка/архитектура/последний запуск |
| Материнская плата и BIOS | Модель/производитель, версия и дата BIOS; серийные номера **выключены** по умолчанию |
| CPU и RAM | Модели CPU, ядра/потоки, частота; модули RAM, слоты, объём, частота, производитель |
| GPU, экраны, принтеры | Модели/версии драйверов, мониторы, принтеры и порты |
| Диски | Модель, интерфейс, объём; разделы, тип ФС, занято/свободно |
| Сеть | Физические и виртуальные адаптеры, имя/описание, статус, **MAC**, скорость, ifIndex; IP v4/v6, шлюзы, DNS, сетевые профили |
| Пользователи | Локальные имена, SID, активна/отключена, **PasswordRequired**, время последней смены пароля (если доступно), последний вход (если доступен), возможность сменить пароль |
| Группы | Локальные встроенные **Администраторы**, **Пользователи**, **Пользователи удалённого рабочего стола**, **Операторы архива** по SID; члены, тип, источник, SID, предупреждения об усечении |
| Текущий сеанс | Windows-пользователь и наличие административной роли в текущем токене (это не проверка членства всех доменных пользователей) |
| Подключённые устройства | PnP, помеченные Windows как present, имена, классы, статусы и проблемы, общая численность; InstanceId только при отдельной опции `-IncludeSerialNumbers` |
| ПО | Частичный список установленных программ по uninstall-ключам реестра, версия, издатель; **без Win32_Product** |
| Обновления | Последние KB/hotfix |
| Службы | Автозапускаемые службы, которые сейчас не работают; это **не подтверждённые инциденты** |
| Защита | Брандмауэр, Defender, другие зарегистрированные антивирусы, UAC, TPM, Secure Boot, состояние BitLocker **без ключей восстановления** |
| События Windows | До восьми ошибок и критических событий системного журнала за последние сутки |

## Чего отчёт НЕ доказывает

- `PasswordRequired=true` означает, что Windows требует пароль, **но не доказывает наличие непустого пароля**. `PasswordLastSet` может помочь оценить историю, но также не доказывает текущее состояние. Проверка конкретного пароля, получение хеша или попытки входа **не выполняются**.
- Члены локальной группы «Администраторы» — **не полный аудит эффективных прав**, вложенных доменных групп, GPO и временного повышения привилегий. Для полноценного аудита нужна отдельная корпоративная методика.
- Отсутствие сведений о BitLocker, антивирусе, ПО или устройствах может означать недостаточные права, несовместимость командлета либо ошибку запроса. Это **не равно отсутствию защиты/оборудования**.
- Выборка усечена лимитом **65 536 байт JSON** в прошивке. PnP ограничен параметром `MaxPnpDevices` (в автоматическом запуске — 80), программы — 45, группы — 40 членов, остальные списки также имеют ограничения.
- MAC адрес интерфейса может быть виртуальным, изменённым или рандомизированным Wi-Fi MAC; его нельзя считать неизменным идентификатором ПК.

## Безопасность

Текущий BLE интерфейс **без PIN и сопряжения**. Имя ПК, MAC, имена локальных/доменных участников групп и IP могут быть конфиденциальными служебными данными. **Не использовать на производственных и корпоративных ПК без согласования с IT/ИБ и аутентификации обмена.** Параметры ОС и устройства могут содержать сведения, которые не нужно публиковать. Никаких паролей, хешей паролей, сертификатов ЭП, ключевых контейнеров, токенов VPN, SSID-паролей или документов пользователей сборщик не извлекает.
