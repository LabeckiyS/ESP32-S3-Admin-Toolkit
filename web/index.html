Диагностика Windows · v0.4.0

Подключи T-Dongle-S3 к разблокированному Windows-ПК. Устройство не меняет язык Windows автоматически.

При RUS запуск заблокирован во избежание ошибочного ввода команды. Переключи раскладку на самом ПК, затем выбери ENG здесь. Автоматического Win+Space нет.

Быстрая проверка не запрашивает подробные списки PnP, программ, служб и журналов Windows. Расширенная передаёт больше данных.

«Последний отчёт ESP32» читает данные из памяти прибора и не запускает проверку текущего ПК. Если новая диагностика завершилась ошибкой, здесь может остаться отчёт другого компьютера.

Компьютер пока не обследован.

Технический отчёт ПК

Отчёт из памяти ESP32; сверяй имя ПК и время сбора.

Отчёт представлен обычным текстом. Можно выделить его вручную или нажать кнопку копирования. Скачивание файлов не используется.

Журнал диагностики

Ожидается подключение устройства.

Диагностика запускается кнопкой «Старт» на разблокированном компьютере. Результаты доступны для копирования из технического отчёта.

Панель загружается с GitHub Pages, но текст клавиатуры и отчёты по сети GitHub не отправляются: обмен с прибором идёт напрямую через Web Bluetooth.
