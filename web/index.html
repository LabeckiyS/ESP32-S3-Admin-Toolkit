Журнал диагностики

Ожидается подключение устройства.

Диагностика запускается только кнопкой «Старт» на разблокированном компьютере. PowerShell открывается видимо и может быть заблокирован корпоративными политиками. Без PIN/BLE pairing передавай только тестовые несекретные данные.

Панель загружается с GitHub Pages, но текст клавиатуры и отчёты по сети GitHub не отправляются: обмен с прибором идёт напрямую через Web Bluetooth.
