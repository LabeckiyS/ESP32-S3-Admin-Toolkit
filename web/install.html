Установка с компьютера

Перед прошивкой: текущая клавиатура v11.1 будет заменена. Сохрани возможность отката. Установка может стереть настройки и сохранённые отчёты на флеш-памяти платы. Используй USB-порт личного/тестового компьютера, а не производственного оборудования.
  1. Открой эту страницу на Windows ПК в Chrome или Edge по HTTPS. Нужен доступ к интернету для загрузки установщика и прошивки.
  2. Отключи T-Dongle-S3 от USB. Зажми BOOT, вставь устройство обратно в USB и отпусти кнопку через 2–3 секунды.
  3. Нажми «Установить Admin Toolkit», выбери порт USB JTAG/serial debug unit (или соответствующий порт ESP32-S3).
  4. Подтверди установку в диалоге браузера и дождись завершения. Переподключи плату без удержания BOOT.
  5. На телефоне открой панель управления, подключись к AdminToolkit-S3 через BLE. Первой откроется «Клавиатура»; «Диагностика» — вторая вкладка.
Требуется Chrome или Edge на компьютере с поддержкой Web Serial. Открой страницу через HTTPS.

Если установка не начинается: закрой PlatformIO, Arduino IDE, терминалы COM-порта и проверь, что плата действительно вошла в BOOT. Доступность USB-порта зависит от драйверов и политик компьютера.

Файлы прошивки публикуются автоматически только после успешной сборки GitHub Actions; если manifest или .bin недоступны, установка не выполнится.

Вернуть прежнюю клавиатуру

Если требуется откат, используй проверенный веб-установщик клавиатуры v11.1. Новая объединённая прошивка пока не проверена на физической плате.
