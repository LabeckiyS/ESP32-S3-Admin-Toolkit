# Быстрый запуск v0.2 (тестовый ПК)

1. Собери `firmware/` через PlatformIO (`pio run`); предпосылки описаны в `README.md`.
2. Сохрани существующую прошивку клавиатуры v11.1 и прошей тестовую ESP32-S3. Нужен родной USB OTG порт платы.
3. В Windows 10/11 открой разблокированный рабочий стол, установи раскладку **ENG**, убедись, что PowerShell и USB CDC не блокируются политиками.
4. Вставь T-Dongle-S3 в USB. В «Диспетчере устройств» должен появиться виртуальный COM-порт Espressif VID_303A и HID-клавиатура. Если нет — сначала проверь USB.
5. На Samsung Galaxy S25 Ultra открой `web/index.html` через HTTPS (например, собственный GitHub Pages с выложенными файлами `web/`) в Chrome. Нажми **Подключить ESP32**, затем **Старт диагностики**.
6. На Windows должно открыться **видимое** окно PowerShell. Команда, введённая по USB HID, попросит скрипт по CDC, проверит SHA-256 и штатно запустит его. **Не вводи ничего с клавиатуры до окончания работы.**
7. Дождись сообщения `P|DONE` в панели и получения отчёта по BLE. Отчёты также будут локально сохранены в `%TEMP%\AdminToolkit-Reports`.

**Если не получилось:** смотри ошибку в окне PowerShell, проверяй раскладку ENG, USB CDC и Windows Execution Policy. Не включай `-ExecutionPolicy Bypass` и не отключай защиту. Данный проект ещё не испытан на физической плате.

**Ограничение безопасности:** BLE без PIN и bonding не аутентифицирует инициатора команды RUN и не защищает отчёт. Используй только на согласованных тестовых компьютерах; не оставляй прибор без присмотра.
