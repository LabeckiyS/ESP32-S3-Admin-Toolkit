# Changelog

## v0.3.0 (2026-11-15)

- Одна BLE-панель с вкладками. При каждом открытии первой показывается «Клавиатура».
- USB HID клавиатура и мышь в общей прошивке с USB CDC для Windows-отчётов.
- Отправка текста на ПК небольшими BLE-пакетами, подтверждение после набора, UTF-8 кириллица при раскладке RUS.
- Базовые клавиши, мышь, чувствительность и прокрутка.
- Диагностика Windows по кнопке во второй вкладке; копирование и скачивание TXT/JSON.
- BLE без PIN, bonding и Wi-Fi. Физические проверки ещё требуются.

## v0.2.0

- Windows-инвентаризация с запуском PowerShell по явной команде из BLE-панели, USB CDC и выгрузкой отчёта на телефон.
